# RacerAPI 1.0

RacerAPI is a modular, NestJS-inspired Python framework powered by FastAPI.

It provides feature modules, a layered API/service/repository architecture, dependency injection, plugin hooks, project and module generators, database tooling, and Poetry-based dependency management.

Start with the [Getting Started guide](getting-started.md), then review [Architecture](core/architecture.md) and the [Module System](core/module-system.md).
